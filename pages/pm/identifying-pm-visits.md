# Identifying PM Visits
Status: Archived

## When This Is Used

To find which PM visits need attention, using the status labels on the PM list.

## Status labels

| Label | Meaning |
| --- | --- |
| Parts | Parts are ordered, and scheduling waits on delivery |
| PM X | Parts have arrived, and the visit is ready to schedule |
| A date | The scheduled visit date |
| Notes | The work is done, but technician notes are still needed |
| PM Complete | Done |

![The PM status labels](identifying-pm-visits-01.png)
![How the labels look on the list. Customer names are blurred.](identifying-pm-visits-02.png)

## Steps

1. Filter the Status column to PM X to see every visit that's ready to schedule.
2. Sort by Job # to bring the earliest visit for each agreement to the top.
3. Filter or sort by Tech to plan one technician's week.
