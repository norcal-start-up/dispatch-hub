# Billing Readiness Requirements
Platform: ServiceTitan
Status: Active

## When This Is Used

The short version of the [Job Completion Checklist](job-completion-checklist), for a quick final pass.

## Final pass

- [ ] All appointments completed
- [ ] Customer PO filled in
- [ ] Requested By, first and last name
- [ ] Salesperson and Supervisor
- [ ] Notes say the job is complete
- [ ] PCard receipts match
- [ ] POs received with invoices
- [ ] Required forms completed
- [ ] Hours submitted correctly
- [ ] Correct rate sheet
- [ ] Tax Zone set to CAEX
- [ ] Service Vehicle Fee, T&M only
- [ ] Margin isn't negative
- [ ] Job has a subtotal
