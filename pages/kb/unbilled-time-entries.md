# Unbilled Time Entries
Platform: ServiceTitan
Status: Active

## When This Is Used

When a technician needs to log time for vehicle maintenance, training, or a job walk.

## Steps

1. Select the clock icon on the main screen.
2. Click Add Timesheet, in the top right.
3. Choose the timesheet activity, such as Meeting, Training, or Travel.
4. Set the duration in hours and minutes.
5. Add a memo with as much detail as possible. For example, "Job walk for [customer], [description]."
6. Click Add Entry, then Add Timesheet.
