# Creating New Suppliers
Platform: ServiceTitan
Status: Active

## When This Is Used

When you need a PO for a vendor that isn't in the system yet.

## Steps

### Set up the vendor in COINS

1. Have the supplier fill out a Vendor Form and a W9.
2. Send both to the Accounts Payable mailbox. Use the New Vendor Setup in COINS template in [Email Templates](email-templates).

### Then add them to ServiceTitan

1. Once the vendor has a COINS account number, email the ServiceTitan vendor setup contacts with the supplier name, address, and a screenshot of the COINS account.

The mailboxes and contacts are in the Internal Support Directory in the [Onboarding Folder](onboarding-folder).

## Required Information

- Vendor Form
- W9
- Supplier name and address
- COINS account number screenshot
