# Purchase Order Overview
Platform: ServiceTitan
Status: Active

## When This Is Used

The kinds of POs, what each one is for, and how they're closed out.

## PO types

| Type | Used for |
| --- | --- |
| Material | Job-related parts, tools, or subcontractors |
| Truck stock | Parts that don't belong to a specific job |

Every PO is closed out by attaching a copy of the invoice.

## Required Information

- Supplier name
- Job number
- Parts list

## Common Errors

- Choosing Material when the work is really a subcontractor's. See [Material or Subcontractor PO?](differentiating-po-requests)
