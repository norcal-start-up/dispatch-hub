# Creating New Locations
Platform: ServiceTitan
Status: Active

## When This Is Used

When an existing customer needs a new service location in ServiceTitan.

## Steps

1. Search for the customer first. Most "new" locations belong to a customer that already exists.
2. Email the Accounts Receivable mailbox with:
   - Location Name: customer, city, and street number. For example, Example Medical Fremont 1234.
   - The location address
   - The customer account number and a screenshot of the account
3. Use the New Location Setup template in [Email Templates](email-templates).

![The customer account card in ServiceTitan. The ID and address are blurred.](creating-new-customer-locations-01.png)
![An example request email](creating-new-customer-locations-03.png)

## Required Information

- Location name and address
- Customer account number
- Screenshot of the account

## Common Errors

- Requesting a location for a customer that doesn't exist yet. Set up the customer first.
- Creating a duplicate. Search by name and by address before you ask.
