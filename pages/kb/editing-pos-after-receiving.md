# Editing POs After Receiving
Platform: ServiceTitan
Status: Active

## When This Is Used

When a received PO needs a change.

## The short version

You can edit until you can't. If the Edit button is grayed out, Accounts Payable has already processed the PO.

| If | Then |
| --- | --- |
| AP hasn't processed the PO | Make your edits |
| AP has processed the PO | Create a new PO |

> Tip: You can add more than one invoice to a PO, as long as AP hasn't touched it yet.
