# Creating Purchase Orders
Platform: ServiceTitan
Status: Active

## When This Is Used

To create a PO for a job in ServiceTitan.

## Steps

1. On the job, click Invoice.
2. Choose Add a purchase order from the left-hand menu.
3. Select the supplier from the Vendor dropdown.
4. Under Inventory Location, select the technician's name. Or switch to Warehouses and select the warehouse.
5. Add part lines. Use Material or Subcontractor. Don't add a Freight line.
6. Open the Create dropdown and choose Create as Sent.

- Supplier name
- Job number
- Technician or warehouse location
