# Assessing Request Severity
Status: Active

## When This Is Used

When a customer has requested emergency service and you're unsure how to triage.

## Steps

1. Get as much detail as you can from the customer.
2. Check the dispatch board for technician availability.
3. If no one's free, use the closest lead technician.
4. Share the problem description and every relevant detail with them.
5. Have the technician call the customer to talk it through and decide how severe it is.
6. Schedule based on the outcome:
   - De-escalated: schedule for the next day or later.
   - Escalated: coordinate a same-day visit.
