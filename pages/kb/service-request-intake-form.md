# Service Request Intake Form
Status: Active

## When This Is Used

Whenever a request comes to you directly by phone or email. Capture these details before you hang up. A printable version is in the [Onboarding Folder](onboarding-folder).

## Contact information

- Company name
- Requestor first and last name
- Phone number
- Email

## Service location

- Street address
- Building number
- Other relevant details
- Site contact name and number

## Scope of work

- Description of the issue
- Affected assets: types, unit numbers, and so on
- Severity or urgency
- The technician they normally work with, if any

## Asset details

- Asset name
- Where the asset is on site
- Equipment tag
- Make
- Model and serial number

## Appointment confirmation

- [ ] Technician visiting
- [ ] Date and time of the visit
- [ ] Confirmed with the customer
