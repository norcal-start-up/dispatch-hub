# SharePoint Directory

Where to find the working files on the NorCal Service SharePoint site. Everything below opens from the [Onboarding Folder](onboarding-folder) or the NorCal Service site.

| File | Where it lives | What it's for |
| --- | --- | --- |
| Estimated Hours | NorCal Service › Customer Related › your customer | The customer spreadsheet lists estimated hours |
| Open SO and PM List | NorCal Service › Dispatch | Notes and tracking on active jobs, plus the PM Details tab with annual maintenance schedules |
| PM Material Lists | NorCal Service › Dispatch › PM Material Lists › current year | Premade parts lists for each PM customer |
| Service Report template | NorCal Service › Dispatch | Blank service report |
| Service Request Intake Form | NorCal Service › Dispatch | Printable intake form |
| Vendor Contact Info | NorCal Service › Dispatch › Vendor List | Vendor account numbers and contacts |

> Note: File names change from year to year. If something isn't where this page says, search SharePoint for the file name and update this page.
