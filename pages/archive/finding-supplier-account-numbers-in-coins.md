# Finding Supplier Account Numbers in COINS
Platform: COINS
Status: Archived

## When This Is Used

To look up a supplier's COINS account number, usually for [Creating New Suppliers](creating-new-suppliers).

## Steps

1. In the left menu, open Accounts Payable, then Suppliers, then Suppliers Inquiry.
2. In the bottom right, change the search type as needed.

![Accounts Payable, Suppliers Inquiry. Account details are blurred.](finding-supplier-account-numbers-in-coins-01.png)
![Change the search type in the bottom right](finding-supplier-account-numbers-in-coins-02.png)

## Required Information

- Supplier name

## Common Errors

- Not finding the supplier by name. Try an asterisk before and after the name.
- Still nothing. Search by address.
- Still nothing. Check with a teammate. The supplier may need to be set up as new.
