# Creating Jobs in ServiceTrade
Platform: ServiceTrade
Status: Archived

## When This Is Used

The second half of opening a legacy job: after the service order was created in COINS, the job was created and dispatched in ServiceTrade.

## Steps

1. Go to Customers, then Companies, and search for the company.
2. Select the location and click Add a Job.
3. Service Vendor: Southland Industries
4. Service Due: Due this month
5. Pick the job type:

| Job type | Used for |
| --- | --- |
| Repair | Quoted or T&M work |
| Service Call | Planned, non-urgent service |
| Urgent Service Call | Same-day or next-day requests |
| Emergency Service Call | After-hours requests |
| Preventative Maintenance | Scheduled maintenance |
| Start Up | Start-up work |

6. Select the service, or create a new one:
   - Asset: if it applies
   - Service Line: matches the request
   - Estimated Duration: from the quote spreadsheet
   - Description: matches the service order description
   - Schedule Techs: places it on the technician's unscheduled board
7. Click Create Job.
8. Upload the quote so technicians can see the request.
9. Add the cost code to the job's Tag. See [Cost Code Structure](cost-code-structure).
