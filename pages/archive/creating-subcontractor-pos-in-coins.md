# Creating Subcontractor POs in COINS
Platform: COINS
Status: Archived

## When This Is Used

Legacy POs for subcontracted work.

## Steps

1. Start the same way as a [material PO](creating-material-pos-in-coins).
2. On the line, use the code SUBS instead of MATL.
3. The Cost Type fills in with a default. Change it to AEX if there's an agreement, or NAB if there isn't.
4. Labor is tax-exempt, so subcontractor lines always use the tax code CAEX.
