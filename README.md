# Dispatch Hub

The knowledge base for NorCal Service dispatchers. It covers the full job lifecycle, from the first service request to Ready to Bill, plus preventive maintenance, parts and purchase orders, scheduling, and a four-week onboarding path for new dispatchers.

**Live site:** https://crystal-jeffers.github.io/dispatch-hub/

## Who it's for

- **New dispatchers** who want a guided first month and a place to look things up.
- **Experienced dispatchers** who need a quick refresher on a less common task.
- **Trainers** who want a shared checklist for what to cover and in what order.

## What's inside

| Section | What it holds |
| --- | --- |
| Start Here | The four-week onboarding path, the trainer checklist, the daily workflow, and a self-check quiz |
| Knowledge Base | Active how-to articles, grouped by job lifecycle stage |
| Preventive Maintenance | PM planning, part ordering, booking, service reports, and the PM tracking workbook |
| Reference | Abbreviations, email templates, directories, and shared links |
| Archive | Legacy ServiceTrade and COINS workflows, kept as context for older jobs |

## Editing

Every page is a plain Markdown file. No code is needed. Open any page on the site and click **Edit this page**, or see the full guide on the site under Reference, Editing This Hub.

| What | Where |
| --- | --- |
| Articles | `pages/` |
| The menu | `nav.md` |
| SharePoint links | `pages/reference/shared-links.md` |
| Pictures | `assets/img/` |

The design lives in `assets/style.css` and `assets/render.js`. Writers never need to open them.

## Data security

This repository is public, so it contains no confidential information. Names, contact details, account numbers, cost codes, and addresses live in the Southland SharePoint, where access requires a Southland login. Screenshots are blurred before upload.

If you spot sensitive information on the site, report it right away so it can be removed.
